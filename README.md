# Zeeshan-Ijaz
A modern, responsive, and visually appealing portfolio website designed to showcase my skills, projects, experience, and professional background.

## Live Portfolio

- Visit the live portfolio at: [https://zeeshan-ijaz-porfolio.vercel.app/](https://zeeshan-ijaz-porfolio.vercel.app/)

## Contents

- `index.html` - Main portfolio landing page.
- `style.css` - Portfolio stylesheet.
- `script.js` - Website behavior and interactions.
- `parse_docx.py` - Python script for parsing `.docx` files.
- `diabetes.csv` - Diabetes dataset for analysis.
- `Salary_Data.csv` - Salary dataset for analysis.
- `updated_data.txt` - Additional data or notes.
- `images/` - Image assets used by the portfolio.
- `profile.png` - Profile image used on the portfolio page.
- `resume.pdf` - Resume document.

## Notes

- The live portfolio is deployed on Vercel.
- This repository contains both web assets and Python project files.
